# Code of Conduct

Data for AI is an open, vendor-neutral and professional community. This code applies at meetups, in community chats and on GitHub. We ask everyone who takes part to:

- **Be respectful.** Disagree with ideas, not with people.
- **Keep it technical.** No sales pitches.
- **Respect privacy.** Don't share anyone's contact details, photos or messages without their consent.
- **Credit others' work.** Speakers' slides and words belong to them.

If something goes wrong, contact an organizer privately, through any community channel you already use. If you have no private channel, open an issue in the [dataforai/community](https://github.com/dataforai/community/issues) repository that says only that you want to report something. Issues are public, so do not name anyone or describe what happened. An organizer will reply there to set up a private way to talk. Organizers are listed under Maintainers in the [community README](https://github.com/dataforai/community#maintainers).
